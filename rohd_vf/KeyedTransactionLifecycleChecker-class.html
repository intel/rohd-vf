KeyedTransactionLifecycleChecker

KeyedTransactionLifecycleChecker<KeyType, ResourceType> class

Tracks outstanding keyed transactions and their attributed resources.

Tests call observeRequest for each accepted request and observeResponse for every accepted response beat. A response only releases a key when its caller-provided completes argument is true. observeCancellation records an explicit terminal cancellation. Every method is deterministic and does not require a particular hardware interface or protocol payload type.
